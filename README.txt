JARVIS install fix

2. Upload both PNG files into the existing icons folder:
   icons/icon-192.png
   icons/icon-512.png
3. Keep index.html and sw.js unchanged.
4. After committing, wait for GitHub Pages to redeploy, refresh the site in Chrome,
   then try Install app / Add to Home screen again.
